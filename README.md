# Monthly Key Assets

Assets repository for the Monthly Key (MK) rental platform.

## Structure

- `hero/` - Hero section background images and videos
- `properties/` - Property seed images (apartments, villas, studios)
- `cities/` - Saudi Arabia city images (Riyadh, Jeddah, Madinah)

## Usage via jsDelivr CDN

All assets can be accessed via jsDelivr CDN using the following pattern:

```
https://cdn.jsdelivr.net/gh/raneemndmo-collab/assets@main/<folder>/<filename>
```
